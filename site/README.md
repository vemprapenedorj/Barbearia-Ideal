# Site / Landing Page — Barbearia Ideal

Esta pasta armazena o código e os recursos visuais da Landing Page da Barbearia Ideal.

### Requisitos principais:
- Foco em contato via WhatsApp para dúvidas e localização; atendimento por ordem de chegada, sem agendamento
- Layout responsivo para smartphones
- Apresentação clara de serviços, valores médios (se aplicável), horários de funcionamento e diferenciais (climatizado, café e bebidas)
- Botão flutuante de WhatsApp
